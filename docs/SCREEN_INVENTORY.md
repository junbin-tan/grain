# Screen inventory

Screenshots are in [docs/screenshots](screenshots/). All are from the real app (`tauri dev`) on real data produced by the end-to-end run.

| # | Screen | File(s) | States implemented |
|---|---|---|---|
| 1 | Onboarding | `01a`–`01e` | Welcome → Privacy → Your Mac (hardware detection, warnings for Intel/low RAM/low disk) → Languages (multi-select) → Models (recommended ASR + LLM + optional embeddings, real downloads with progress/cancel/resume) → Permissions (mic, screen & system audio; request, open System Settings, re-check) → Audio test (live meters, 5 s throwaway capture) → Ready (first-meeting walkthrough). Skip on optional steps. |
| 2 | Meeting home | `02-home` | Banner if models are missing; "Start a meeting" card; list grouped Today/Yesterday/weekday/date with time, duration and preview; status badges (Recording, Paused, Interrupted, Transcribing x%); filter; empty state; delete with confirmation. Upcoming meetings: not available (no calendar integration). |
| 3 | Active meeting | `03a`, `03b` | Pre-record dock (computer-audio toggle, Mic, Start ⌘R, consent line); recording dock (timer, mic/system level bars, mark ⌘M, pause/resume ⌘⇧P, live transcript, Stop); live transcript side panel; recording indicator in sidebar, title row and menu bar; notes editable throughout; warnings for missing permission or source. |
| 4 | Meeting details | `04a`, `04b`, `04c` | Editable title; date · duration · template; tabs My notes / Enhanced notes / Transcript (⌘1–3); enhanced versions, Regenerate by template, verification banners, action-item tracking with owner/deadline/suggested/unverified badges; transcript search, inline correction (original kept), marks, jump to timestamp; Ask panel; banners for interrupted recording (transcribe the recovered audio) and missing speech model. |
| 5 | Global search | `05-search` | ⌘K palette; filters All / Transcripts / Notes / Action items; "By meaning" toggle (enabled when an embedding model is installed); results grouped by meeting with highlighted excerpts and timestamps; keyboard navigation; opens the matching tab at the matching moment. |
| 6 | AI chat | `06-ask-grain` | Chat history (new, open, delete); suggestions; streamed answers; numbered citation chips; source cards (meeting, date, timestamp, excerpt) that navigate; "couldn't find that" refusal with no sources; hint when no LLM is installed. |
| 7 | Model management | `07a`, `07b`, `08c` | Tabs Transcription / Notes & chat / Search by meaning; search by name or language; Installed / Recommended for your languages / More models (every curated model by default, "My languages only" filter, "Show all" adds experimental ones, "Doesn't support X" note); quantisation picker with per-quant size; Download = download, verify, then switch (as in Handy), also from the Settings dropdown; "Add model file…" for your own .gguf; grades, speed, size, licence, streaming/translate badges, RAM warning, experimental badge; download progress and speed, cancel, resume, verify, use, delete with inline confirmation; storage usage; hardware summary. |
| 8 | Settings | `08a`, `08b` | General (default template, your name, rerun setup); Audio (mic device, computer audio, test, permissions); Transcription (model, live/after, spoken language, your languages); AI notes & templates (model, custom template CRUD); Search (embedding model, rebuild index); Privacy & data (data folder, storage, keep-audio retention, delete all, delete everything, consent guidance); Shortcuts; About. |
| 9 | Export | `09-export` | Markdown, plain text, JSON, PDF (print dialog), WAV (disabled without audio); preview; native save dialog. |
| 10 | Errors and recovery | throughout | Missing permissions (banner + toast with Open Settings); missing models (banners and buttons to Models); failed download (row error, resume); insufficient storage (download refused with sizes); unsupported hardware (onboarding warnings); recording errors (system audio stopped, mic disconnected with fallback); transcription failures (toast, retry via Re-transcribe); inference failures (toast, model memory warning); interrupted meetings (Interrupted badge, recovered-audio banner, launch toast). |
| — | Action items | `10-action-items` | All meetings' action items; open/done/all; "Assigned to me" (owner = Me); toggle status; links to the meeting. |
