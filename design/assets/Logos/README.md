# Logos

The kernel mark, the wordmark and their lockups. Full-colour files use `ink` #1E1A15 bars with the centre bar in `malt` #C8862E. Reverse files use `paper` #F6F1E7 bars with the centre bar in dark-theme `malt` #E0A04A. Mono files are a single ink (`ink` or `paper`). All wordmarks are outlined letterforms; don't retype them. The PNGs are 1200px (lockup) and 1024px (mark) wide, on transparent backgrounds.
